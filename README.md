# 📊 Engineering Manager

> Prepare your 1:1s in 30 seconds, not 30 minutes

A Vienna content profile for engineering managers. Includes quick actions for 1:1 prep, sprint retros, performance reviews, cycle time analysis, stakeholder updates, and team load balancing.

## What's included

- **Quick Actions** — Prepare 1:1s, generate sprint retros, draft performance reviews, track cycle time, write stakeholder updates, analyze review load
- **Skills** — Getting started guide for Vienna profiles
- **Plugins** — Linear for sprint and project tracking

## Install

Fork this profile in Vienna:

```
vienna://profile/github.com/tryvienna/profile-engineering-manager
```

Or go to **Settings → Profiles → Fork** and paste:
```
https://github.com/tryvienna/profile-engineering-manager.git
```

## Customize

After forking, this profile lives at `~/.vienna/profiles/engineering-manager/`. Edit any file to make it yours — add quick actions, swap plugins, tweak skills.

## Share

Push your customized profile to your own GitHub repo and share the `vienna://profile/...` link. Others can fork your version in one click.
